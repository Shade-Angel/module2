# Проект 2. Cashback Merge

Мини-игра в духе 2048 на поле `4x4`. На поле появляются плитки с кэшбэком,
две одинаковые объединяются в следующую:

```text
1% + 1% = 2%    2% + 2% = 4%    ...    16% + 16% = 32%
```

У игрока ограниченное число ходов, цель — собрать максимальный кэшбэк.

Но у проекта есть второй, продуктовый слой. По итоговой плитке начисляется
награда, и эта награда стоит компании денег. Поэтому максимальную награду
должна получать ограниченная доля игроков — например, не больше `20%`.
Проверяется это симуляцией на тысячах «игроков» до запуска акции.

Задание разбито на три merge request'а. Делай их по очереди.

# MR1
**<p style="color: red">Что сделано:</p>**

**Модель игры:**
- Поле 4x4 (Board) с защитой от выхода за границы
- Плитки хранят уровень кэшбэка (1%, 2%, 4% и т.д.)
- Состояние игры (GameState) - это снимок: поле, остаток ходов, счет, seed
- Начальное поле генерируется по seed - два раза спавним плитки, и всё детерминировано

**Конфиг:**
- Загружается из JSON через Jackson (ConfigLoader)
- Валидируется сразу при создании (CampaignConfig)
- Проверяется что movesLimit > 0, список spawn-правил не пуст, вероятности в диапазоне [0, 1] и в сумме дают ровно 1

**Вывод поля:**
- Board.toString() рисует сетку 4x4 в консоль
- Пустые клетки показываются как ` . `, числа выравниваются по 3 символа

# MR2
**<p style="color: red">Что сделано:</p>**

**Логика ходов:**
- Реализован класс `GameEngine` с методом `applyMove`, обрабатывающим направления `UP`, `DOWN`, `LEFT`, `RIGHT`
- Логика слияния в `LineProcess`, плитка может слиться только один раз за ход
- Подсчёт очков (`score`)

**Обработка состояний:**
- Некорректный ход не тратит ход, не изменяет поле и не создаёт новую плитку
- После каждого валидного хода спавнится ровно одна новая плитка через `TileSpawn`
- Игра не завершается автоматически при достижении плитки 32%, а идёт до исчерпания `movesLimit`


## Структура

| Файл | О чём |

| `engine/LineProcess.java` | Изолированная логика: фильтрация, слияние линии, запрет двойного слияния и подсчет очков за ход |<br>
